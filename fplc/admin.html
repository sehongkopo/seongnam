이 기록에서 켜지는 경보

경보횟수첫 발생

첫 줄이 열 이름인 표를 읽으며 구분자는 탭이나 쉼표입니다. 열 이름은 Time (min), Volume (mL), UV 280 (mAU), Cond (mS/cm), Conc B (%), Flow (mL/min), System pressure (MPa), pH, Fraction, Run log 형식입니다. 시간과 UV 열은 꼭 있어야 하고, 한글이 EUC-KR 로 저장된 파일도 읽습니다. 단계는 런 로그의 Equilibration, Inject, Wash, Gradient, Strip, Re-equilibration 같은 낱말에서 읽습니다.

런 시각

런 시작 시각부터 흐른 시간만큼 기록을 보여 줍니다. 기본값은 오늘 0시 시작에 반복이라, 60분짜리 기록이면 매시 정각에 런이 새로 시작합니다.

경보 기준과 컬럼 정보

경보는 조건이 몇 초 이어져야 켜지고 5 s 동안 정상이어야 꺼집니다. 컬럼 부피와 이미다졸 농도는 경보에 쓰지 않고, 부피를 CV 로 바꾸고 농도 B 를 이미다졸 농도로 바꿔 보여 주는 데 씁니다.
