# FPLC 정제 실시간 모니터

**▶ [모니터 열기](https://sehongkopo.github.io/seongnam/fplc/)** &nbsp;|&nbsp; [관리자 페이지](https://sehongkopo.github.io/seongnam/fplc/admin.html)

ÄKTA pure 150 으로 돌린 His-tag IMAC 런 기록(`data.txt`, 60 min, 1 s 간격)을 실시간 데이터로 가정하고 감시하는 대시보드다.
런 시작 시각부터 흐른 시간만큼 기록을 보여 주므로, 아직 오지 않은 시간의 값과 피크, 경보는 화면에 나오지 않는다.
설치 없이 브라우저에서 바로 열린다.

> 지금 들어 있는 `data.txt` 는 실제 내보내기 파일이 아니다. 원본 파일의 열 구성과 곡선 모양을 따라 다시 만든 대용 기록이다.
> 원본 `AKTApure150_HisTag_IMAC_60min FPLC data.txt` 를 `data.txt` 라는 이름으로 덮어쓰면 그대로 읽는다.

## 화면

| 영역 | 내용 |
|---|---|
| 유로 그림 | 완충액 A·B, 펌프, 믹서, 주입 밸브, 컬럼, UV 검출기, 전도도 셀, 분획 시험관. 값과 밸브 위치, 수집 여부가 함께 바뀐다 |
| 계기판 | UV 280, 전도도, 압력, 유량 |
| 이벤트 요약 | 런 로그, 피크 정점, 경보를 최근 순으로 보여 주고 누르면 상세 내역이 열린다 |
| 경보 표시창 | 경보 10종. 누르면 확인 처리된다 |
| 런 경과 띠 | 지나간 단계, 피크 정점, 변수별 경보 구간 |
| 크로마토그램 | UV 280, 농도 B, 전도도를 한 칸에 겹치고 압력·유량·pH 를 아래에 둔다. 5분·15분·30분·전체 구간 |
| 피크 표 | 정점 시각과 부피, 높이, 면적, 정점의 농도 B 와 이미다졸 농도, 분획 범위 |
| 기록 | 런 로그, 피크, 경보 발생·해제, 운전자 확인, 최근 10초 데이터 |

## 단계와 피크

단계는 런 로그 문장의 낱말(Equilibration, Inject, Wash, Gradient, Strip, Re-equilibration, Method end)에서 읽는다.

피크는 지나간 값만으로 판정한다. UV 가 피크 하한(기본 50 mAU)을 넘으면 피크로 보고, 최고값의 90 % 아래로 내려오면 정점을 확정한다.
하한의 80 % 아래로 내려오면 끝난 것으로 보며, 내려가다가 골짜기에서 30 % 넘게 다시 오르면 그 골짜기에서 두 피크로 나눈다.
면적은 기준선을 빼지 않고 UV 를 부피로 적분한 값이다.

## 경보 규칙

| 경보 | 주의 | 위험 | 지속 조건 |
|---|---|---|---|
| 압력 상한 | ≥ 0.40 MPa | ≥ 0.50 MPa | 3 s |
| 압력 급상승 (막힘 의심) | 최근 60 s 최저값보다 0.10 MPa 넘게 상승 | – | 5 s |
| 압력 저하 (누액 의심) | – | 유량이 있는데 < 0.05 MPa | 5 s |
| 유량 편차 | 설정 유량에서 5 % 넘게 벗어남 | 10 % 넘게 벗어남 | 5 s |
| UV 범위 초과 | ≥ 2000 mAU | ≥ 3000 mAU | 5 s |
| 기준선 미복귀 (세척 부족) | 용출을 시작할 때 UV > 10 mAU | – | 즉시 |
| 구배 이상 (B 펌프 의심) | 농도 B 가 120 s 동안 10 %p 넘게 변했는데 전도도 변화 < 0.2 mS/cm | – | 10 s |
| pH 이탈 | 6.8–8.0 밖 | 0.5 더 벗어남 | 10 s |
| 수집 밖 피크 | – | 용출·스트립 단계에서 분획 수집 없이 UV > 50 mAU | 3 s |
| 센서 값 이상 | – | UV −100–7000 mAU, pH 0–14 밖이거나 전도도·압력이 음수 | 2 s |

경보는 5 s 동안 정상이어야 해제된다. 설정 유량을 따로 넣지 않으면 기록의 유량 중앙값을 쓴다.
기준값은 관리자 페이지에서 바꿀 수 있다.

## 관리자 페이지

- **런 기록 올리기**: `.txt`, `.csv`, `.xlsx`. 첫 줄이 열 이름인 표이고 구분자는 탭이나 쉼표다. 열 대응, 크기, 피크 수, 이 기록에서 켜지는 경보를 미리 보고 적용한다.
  열 이름은 `Time (min), Volume (mL), UV 280 (mAU), Cond (mS/cm), Conc B (%), Flow (mL/min), System pressure (MPa), pH, Fraction, Run log` 형식이며 시간과 UV 열은 꼭 있어야 한다.
  한글이 EUC-KR 로 저장된 파일도 읽는다.
- **런 시각**: 런 시작 시각, 재생 배속, 반복 여부. 기본값은 오늘 0시 시작에 반복이라 60분짜리 기록이면 매시 정각에 런이 새로 시작한다.
- **기준값**: 위 표의 경보 기준, 피크 하한, 컬럼 부피, 완충액 A·B 의 이미다졸 농도.

서버가 없으므로 올린 파일과 설정은 그 브라우저(IndexedDB, localStorage)에만 저장되고 다른 사람의 화면은 바뀌지 않는다.
모든 사람에게 다른 기록을 보여 주려면 저장소의 `data.txt` 를 바꿔 올린다.

## 로컬 실행

```bash
python -m http.server 8071      # http://127.0.0.1:8071
```

`index.html?t=2080` 처럼 `t`(초)를 주면 그 런 시각에 화면을 고정한다(점검용).

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 모니터 |
| `admin.html` | 관리자 페이지 |
| `common.js` | 데이터 읽기, 단계·피크 판정, 경보 규칙, 설정 저장 |
