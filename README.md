# 미생물 배양기 실시간 모니터

**▶ [모니터 열기](https://sehongkopo.github.io/seongnam/)** &nbsp;|&nbsp; [관리자 페이지](https://sehongkopo.github.io/seongnam/admin.html)

E. coli BL21 재조합 단백질 생산 배양의 운전 기록(`data.csv`, 24 h, 1 s 간격)을 실시간 데이터로 가정하고 감시하는 대시보드다.
배양 시작 시각부터 흐른 시간만큼 기록을 보여 주므로, 아직 오지 않은 시간의 값과 경보는 화면에 나오지 않는다.
설치 없이 브라우저에서 바로 열린다.

|---|---|
| 모니터 | https://sehongkopo.github.io/seongnam/ |
| 관리자 | https://sehongkopo.github.io/seongnam/admin.html |

## 화면

| 영역 | 내용 |
|---|---|
| 신호탑 | 정상(녹), 주의(황), 위험(적). 확인하지 않은 경보가 있으면 깜박인다 |
| 경보 배너 | 가장 심각한 미확인 경보와 확인 단추 |
| 계기판 | 온도, pH, DO, 교반. 온도와 pH 는 설정값을 12시 방향에 두고 주의·위험 구간을 색으로 표시한다 |
| 경보 표시창 | 경보 8종. 누르면 확인 처리된다. 해제됐지만 확인하지 않은 경보는 점선 테두리로 남는다 |
| 배양 경과 띠 | 지나간 시간, 사건, 경보 구간 |
| 트렌드 | 10분·1시간·6시간·24시간 구간. 설정값은 점선, 경보 구간은 바탕색으로 표시한다 |
| 기록 | 사건, 경보 발생·해제, 운전자 확인, 최근 10초 데이터 |

경보음은 기본으로 꺼져 있고, 켜면 새 경보마다 울리며 확인하지 않은 위험 경보가 있으면 15 s 마다 다시 울린다.

## 경보 규칙

| 경보 | 주의 | 위험 | 지속 조건 |
|---|---|---|---|
| 온도 편차 | \|T − SP\| > 0.3 °C | > 1.0 °C | 30 s |
| pH 편차 | \|pH − SP\| > 0.025 | > 0.05 | 10 s |
| DO 저하 | DO < SP − 5 %p | DO < 30 % | 10 s |
| DO 급등 (기질 고갈 의심) | 최근 5분 최저값보다 10 %p 넘게 오르고 SP 보다 높음 | – | 60 s |
| 교반 상한 | ≥ 700 rpm | ≥ 800 rpm | 30 s |
| 펌프 연속 가동 | – | NaOH 또는 HCl 이 60 s 넘게 연속 가동 | 즉시 |
| 산·염기 동시 투입 | – | NaOH 와 HCl 이 함께 가동 | 즉시 |
| 센서 값 이상 | – | pH 2–12, DO −2–130 %, 온도 5–60 °C 밖 | 5 s |

경보는 5 s 동안 정상이어야 해제된다. 설정값이 바뀐 뒤 900 s 동안은 온도·pH 편차 경보를 억제한다.
기준값은 관리자 페이지에서 바꿀 수 있다.

## 관리자 페이지

- **운전 기록 올리기**: `.csv` 또는 `.xlsx`(`Raw_1s` 시트 우선). 열 대응, 크기, 이 기록에서 켜지는 경보를 미리 보고 적용한다.
  `data.csv` 형식 외에 ARA 배양기 로그(`Count, pH, DO, Temp, RPM, ACID, BASE, FEED, FOAM, Date`)도 읽는다.
  이때 시간은 `Date` 열에서 계산하고, 펌프 가동은 누적량이 늘어난 시점으로 본다.
- **운전 시각**: 배양 시작 시각(기본은 오늘 0시라서 하루 중 시각이 곧 배양 경과 시간), 재생 배속, 반복 여부.
- **경보 기준**: 위 표의 기준값.

GitHub Pages 에는 서버가 없으므로 올린 파일과 설정은 그 브라우저(IndexedDB, localStorage)에만 저장되고 다른 사람의 화면은 바뀌지 않는다.
모든 사람에게 다른 기록을 보여 주려면 저장소의 `data.csv` 를 바꿔 올린다.

## 로컬 실행

```bash
python -m http.server 8070      # http://127.0.0.1:8070
```

`index.html?t=29400` 처럼 `t`(초)를 주면 그 배양 시각에 화면을 고정한다(점검용).
